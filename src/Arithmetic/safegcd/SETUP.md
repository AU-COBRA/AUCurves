# Running the BLS12-381 Divstep Certificate on a SLURM Cluster

## What this does

Formally proves (in Coq/Rocq, zero axioms) that the Bernstein-Yang divstep
algorithm converges for the BLS12-381 prime. This eliminates the `by_convergence`
axiom from `BLS12_FpInv.v`.

## Prerequisites

1. **Coq 8.15+ or Rocq 9.0** with **native compiler** enabled.

   Best setup (OCaml 4.14 + Rocq 9.0 + native):
   ```bash
   opam switch create rocq-native ocaml-base-compiler.4.14.2
   eval $(opam env)
   opam install -y rocq-native rocq-core.9.0.0 rocq-stdlib.9.0.0
   ```

   Verify native compiler:
   ```bash
   rocq compile -config | grep native
   # Should show: COQ_NATIVE_COMPILER_DEFAULT=yes
   ```

   **Important**: OCaml 5.x does NOT support native_compute (fixed in Rocq 9.3).
   Use OCaml 4.14.

2. **Copy this directory** to the cluster:
   ```bash
   scp -r src/Arithmetic/safegcd/ cluster:~/safegcd/
   ```

## Running

### Option A: SLURM
```bash
cd ~/safegcd
# Edit slurm_certificate.sh: uncomment the opam/module line for your setup
sbatch slurm_certificate.sh 1075    # try tight bound
# If that fails (N too small): sbatch slurm_certificate.sh 1101
```

### Option B: Interactive (screen/tmux recommended)
```bash
cd ~/safegcd
eval $(opam env --switch=rocq-native)
export PATH=~/.opam/rocq-native/bin:$PATH
./build.sh 1075
```

## Timing

| Setup | N=100 (test) | N=1075 (est.) |
|-------|-------------|---------------|
| native_compute, Rocq 9.0, Ryzen 7 | 10s | 3-8 hours |
| vm_compute, Coq 8.18, Ryzen 7 | 27s | days |
| O'Connor's N=724/256-bit (reference) | — | 2.5 days |

The computation ran for 2h35m on Ryzen 7 PRO 7840U with native_compute before
being interrupted. It may have been close to finishing. Expect 3-8 hours total.

## If N=1075 fails

The `native_compute. reflexivity.` will print:
```
Error: Unable to unify "true" with "false".
```
This means N=1075 is too few iterations. Try N=1080, 1085, ..., up to 1101
(the Bernstein-Yang formula upper bound, guaranteed to work).

## After completion

Copy the `.vo` files back:
```bash
scp cluster:~/safegcd/divsteps_bls12.vo cluster:~/safegcd/divsteps_bls12_proof.vo \
    src/Arithmetic/safegcd/
```

Then update `BLS12_FpInv.v` to import the certificate instead of using axioms:
```coq
Require Import Crypto.Arithmetic.safegcd.divsteps_bls12_proof.
(* Use bls12_divstep_prime_inverse instead of by_convergence axiom *)
```
